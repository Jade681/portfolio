# job-interviewer Skill 说明

## 调用关系

`job-interviewer` 是一套可以单独运行的面试官与人才评估 Skill。只要提供岗位/组织需求和候选人材料，它就能独立完成画像校准、笔试或面试设计、逐题面试、针对候选人的反馈、统一评估与面试官复盘。

`job-application-copilot` 只是在进入真实笔试或面试评估阶段时调用 `job-interviewer`。准确说法是：**求职 Skill 调用面试官 Skill**；面试官 Skill 不依赖求职 Skill，也可用于学生组织招新、项目团队选人或未来真实招聘。

- 求职副驾负责整理 JD、候选人证据、简历/网申/作品、风险和现实条件；
- 面试官 Skill 负责独立建立评估画像、选择笔试或面试、生成两层题目、逐题追问、候选人反馈和会后评价；
- 面试结束后，面试官 Skill 再以逐题采访方式帮助面试官反思。

## 完整闭环

```text
岗位与实际任务
→ 显性要求、任务反推与不确定假设
→ 岗位评分卡
→ 岗位统一题
→ 候选人材料定制题
→ 真实市场与业务场景校准
→ 笔试或逐题面试
→ 初步证据整理
→ 按岗位与候选人表现生成反馈
→ 最终证据评估与决策记录
→ 面试官采访式反思
→ 候选人案例、岗位画像与 Skill 分层更新
```

## 候选人反馈

反馈不是固定模板，也不是在面试过程中边问边指导。Skill 会在评估环节明确结束后，根据岗位最高影响任务、候选人的真实回答或作品、证据置信度和组织允许披露的范围，分别生成面试官内部的“证据—反馈映射”和可直接说出口的自然话术。

每个反馈点遵循：**观察到的证据 → 对这个岗位的影响 → 可执行的下一步**。优先给一项有证据的优势和一至两项最重要的改进，不为了显得平衡而虚构表扬，也不把“没有问到”说成“候选人不会”。如果结果尚未确认，反馈与录用/晋级结论必须分开。

## 文件位置

知识库中保存可阅读、可备份的 Skill 副本。当前求职工作区中的 `job-application-copilot` 通过相对路径调用同目录的可运行 `job-interviewer`。如果以后决定把知识库版本设为唯一运行版本，需要同步修改调用路径并验证运行环境。

## 隐私

Skill 本体只保存通用方法。候选人身份、联系方式、录制链接和未公开材料不得进入 Skill 示例与通用参考。

## 真实职场校准

需要时先检索近期同类岗位 JD、正式结构化面试指南、真实业务流程和可信的近期面试记录。题目应模拟岗位中的任务、取舍、约束、交接和失败场景，而不是照搬热门题库。
